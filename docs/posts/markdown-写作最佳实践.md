## ✍️ Markdown 写作最佳实践

Markdown 是最流行的轻量级标记语言，广泛应用于技术文档、博客写作、项目 README 等场景。本文总结了一些实用的 Markdown 写作技巧。

### 基础语法速查

| 语法 | 效果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `[链接文本](https://example.com)` | 超链接 |
| `` `代码` `` | `代码` |

### 代码块

````markdown
```python
def hello():
    print("Hello, World!")
```
````

效果：

```python
def hello():
    print("Hello, World!")
```

### 文章组织

一篇好的技术文章应该：

1. 有清晰的结构层次
2. 使用适当的标题层级
3. 代码和文字搭配合理
4. 配上必要的图示或表格

### 图片引用

```markdown
![描述文本](图片路径)
```

### 引用块

> 引用可以突出重要信息
> 多行引用保持连贯

### 总结

掌握 Markdown 基本语法只需要几分钟，但它能陪伴你整个技术写作生涯。
